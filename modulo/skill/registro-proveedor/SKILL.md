# Skill: Registro como Proveedor

## Proceso
1. Leer solicitud del cliente
2. Identificar campos solicitados y soportes
3. Mapear al maestro usando glosario
4. Generar formulario en formato solicitado
5. Armar paquete con soportes y checklist
6. Solicitar confirmación antes de cualquier acción

## Reglas
- Solo datos del maestro, nunca inventar
- Preparar y pedir confirmación, no firmar/enviar
- Identificadores por país
- Verificar vigencia de soportes
- Datos bancarios solo si se piden
